### Task 5.1 & 5.2: Practice Sandbox Operations
- `mkdir ~/terminal-practice && cd ~/terminal-practice` -> Created and navigated to the practice sandboxed workspace.
- `mkdir my-project && cd my-project` -> Initialized the target practice project directory.
- `mkdir -p src/css src/js src/images docs tests` -> Generated deep subfolder paths concurrently via nested structure flags.
- `touch README.md` -> Created the practice repository markdown readme anchor file.
- `touch index.html` -> Generated a blank html layout tracker.
- `cp index.html backup.html` -> Duplicated the target layout document.
- `mv backup.html docs/` -> Relocated the file to the documents folder.
- `mv index.html home.html` -> Renamed the layout file.
- `rm home.html` -> Deleted the target workspace tracker file.
- `cp -r src/ src-backup/` -> Duplicated the target folder structure recursively.
- `mv src-backup/ archive/` -> Moved the folder block to the archive path directory.
- `rm -r archive/` -> Erased the nested folder architecture block completely.
