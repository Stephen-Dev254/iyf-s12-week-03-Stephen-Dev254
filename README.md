## What I Learned

- **Path Resolving Frameworks:** Mastered standard relative routing mechanisms (`../`) to successfully navigate cross-directory asset delivery hooks and link layers between nested subdirectories and the root directory.
- **Terminal Operations and Scripting:** Built an automated project scaffolding bash script (`new-project.sh`) utilizing variable flags and deep directory layer generation commands (`mkdir -p`) to cut development configuration overhead down to zero.
- **Git Feature Branch Isolation:** Practiced isolated production workflows by implementing standard tracking operations (`git branch`, `git merge`) to safely iterate code without affecting stable deployment states.

## Challenges Faced (Merge Conflict Resolution)
During the branch merging execution simulations, a manual code conflict was triggered inside `README.md` when both `branch-alpha` and `branch-beta` attempted to update the same target text vector. The collision was safely managed by analyzing conflict inline markers directly inside Visual Studio Code's editor pane, manually tracking down structural priorities, choosing the correct execution layer, and finalizing the staging block with a standard resolution commit.
